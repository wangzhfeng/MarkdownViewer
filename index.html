功能特性

不只是渲染 Markdown，更是一套完整的阅读体验。

语法高亮预览

基于 Markdig 渲染管线，支持脚注、Emoji、YAML Front Matter，禁用内联 HTML 阻止脚本注入。

KaTeX 数学公式

完整支持 LaTeX 数学公式渲染，行内与块级公式都能清晰展示。

Mermaid 图表

流程图、时序图、甘特图等 Mermaid 图表直接渲染，无需导出。

代码语法高亮

集成 Highlight.js，多种编程语言代码块都能获得清晰的高亮着色。

文档大纲导航

H1–H6 标题结构一目了然，点击平滑跳转，滚动时自动高亮当前标题。

主题与布局切换

浅色 / 深色主题一键切换，居中窄栏 / 全文宽屏两种布局模式。

Vim 风格键盘导航

j/k 行滚动、d/u 半页、f/b 整页、gg/G 首尾，还有 h/l 横向滚动。

导出 PDF 与链接跳转

按 P 键导出 PDF，点击 Markdown 链接在文件间跳转，外链用默认浏览器打开。

图片与阅读体验

点击图片全屏查看，alt 文本作为标题，顶部渐变蓝色阅读进度条。

常见问题

支持哪些 Markdown 文件后缀？
支持 .md 和 .markdown 后缀的 Markdown 文件。插件通过 DetectString 自动识别并触发预览。
为什么需要安装 WebView2 运行时？
最新版本改用 WebView2（基于 Microsoft Edge 内核）作为渲染引擎，以获得更好的渲染效果和兼容性。较新的 Windows 10/11 系统通常已内置，较旧的系统需要手动安装。
支持中文文件吗？会不会乱码？
完全支持。v1.0.0 已加入文件编码自动检测（UTF-8 / GBK / GB18030），中文 Markdown 文件不会再出现乱码。
需要联网才能使用吗？
不需要。KaTeX、Mermaid、Highlight.js 等前端库已本地打包，完全离线可用，无需联网加载任何外部资源。
可以自己从源码构建吗？
可以。项目基于 C# 与 .NET Framework 4.8，使用 Visual Studio 2017+ 即可构建。仓库根目录提供了 Makefile，运行 make release 即可生成 Release 版本。
支持哪些渲染特性？
基于 Markdig 渲染管线，支持脚注、Emoji、YAML Front Matter，并集成 KaTeX 数学公式、Mermaid 图表和 Highlight.js 代码高亮。为安全起见，内联 HTML 已禁用，可阻止恶意脚本注入。
